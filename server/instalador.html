    Bienvenido a Sotos

    Un ordenador completo dentro del navegador. En unos minutos lo dejamos listo.

    El asistente revisa este servidor, prepara la base de datos, crea tu cuenta de administrador, te deja elegir cómo funcionará y, si hay Docker, instala los servicios opcionales: oficina completa, diagramas, navegador virtual, cine y fotos.

    Modo demostración: los servicios de Docker se simulan; todo lo demás es la instalación real.
    Estás instalando desde otro equipo. Por seguridad, escribe el código de instalación que aparece en la consola del servidor.

    Base de datos

    Sotos trae su propia base de datos: no hay que instalar MySQL ni crear usuarios.

    SQLite
    Integrada en Sotos. Un solo archivo, sin servidor aparte, sin usuario ni contraseña: nadie fuera de Sotos puede conectarse a ella.
    Las contraseñas se guardan con scrypt, las de correo y las bóvedas con AES-256, y cada día se hace una copia de seguridad.
