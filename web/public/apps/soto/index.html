Cómo funciona

Es el mismo formato .soto v1 de SOTO para Windows, hecho con las herramientas de cifrado del navegador.

Clave. Tu contraseña pasa por scrypt (N = 216, r = 8, p = 1; usa 64 MB de memoria a propósito, para que probar contraseñas a ciegas sea muy lento) con una sal aleatoria. De esa clave maestra salen dos subclaves con HMAC-SHA256: una para cifrar y otra solo para comprobar la contraseña.

Cifrado. El contenido va en bloques de 1 MB cifrados con AES-256-GCM. Cada bloque lleva su número y la cabecera como datos autenticados: si alguien cambia, quita o reordena un bloque, el archivo no abre.

Integridad. Cada archivo guarda su huella SHA-256 y se comprueba al extraerlo.

Compresión. Aquí se usa Deflate. SOTO de escritorio también hace Zstandard, Brotli y SOTO-M: esos se pueden listar aquí, pero se extraen en el programa de escritorio.

Si olvidas la contraseña no hay forma de recuperar el contenido. Nadie, tampoco Sotos, puede abrirlo sin ella.
